# 插图素材来源与再生成

本轮插图有两类来源：一类是 Openclipart 的公有领域（Public Domain）矢量素材，另一类是代码绘制的线稿。
所有最终 PNG 都放在 `app/src/main/assets/figures/`，文件名与 `docs/画图提示词.md` 的清单一致。

## 一、公有领域矢量素材

以下素材均下载自 [Openclipart](https://openclipart.org)，详情页标注 **Public Domain**；使用与再分发不受限制。
源 SVG 在 `tools/figure_gen/sources/openclipart/`，渲染后的透明/灰度版本在 `tools/figure_gen/sources/render/`。

素材处理：

- 和弦图去掉了左上角英文标题和灰色星形水印，裁切到指板主体；只保留弦位、品位、按弦指编号与 x/0 标记。
- 电吉他从原彩色矢量转为灰度，并去掉投影；琴头原有的 "Les Caca" 字样在 D1/G1 用深色块覆盖。
- 吉他架转灰度并去掉白底，留作 E3 的备用素材；E3 最终采用代码画的 A 字架，以便与吉他准确对齐。

## 二、代码线稿

其余插图（A/B 组手型、A5 按弦要点、C6–C8 切换关键帧、D2–D5 设备图、E2、F1–F2、G2–G3）
由 `tools/figure_gen/figures.py` 用 PIL 绘制，统一为黑白粗线稿，手指数量由代码固定。

## 三、再生成

```bash
# 全部
python tools/figure_gen/generate.py

# 单张
python tools/figure_gen/generate.py --only a1 c1 d1
```

依赖：Python 3.11+、Pillow。素材合成部分读取 `tools/figure_gen/sources/render/` 中已提交的 PNG，
不需要重新渲染 SVG；若要重做素材，需本机有 Chrome/Edge 与对应 SVG（见 `tools/figure_gen/sources/openclipart/`）。

## 四、已知取舍

- **Dm 缺失**：Openclipart 的开放和弦套图没有 Dm，C4 右图暂用 Dm7（xx0211）替代；它跨度更小，适合手指粗、手掌厚的情况。若必须用 Dm（xx0231），需要另出 `c4_a_dm.png`。
- **A/B 组手型仍偏示意**：可用的 CC0 矢量「手按琴颈」素材缺失。当前版本保证手指数量与按弦位置正确，但形态不如商业插画写实；后续可按 `docs/画图提示词.md` 用文生图替换，文件名保持不变。
- **灰度而非纯黑白**：电吉他素材保留了明暗层次（已去彩色），和弦图为纯黑白线稿。
