## 一、使用说明

1. **每条提示词都要在前面拼上「统一风格前缀」**，保证所有图风格一致。前缀已包含在下列可复制提示词中，无需重复粘贴。
2. 一次只生成一张图；多格图在提示词里明确「分为 N 格」。
3. **图像模型画手容易出错**，所以每张图都要写清「每只手 5 根手指、手指数量正确」；出图后请人工检查手指数量与按弦位置，错了就重生成（这是常态，不必纠结）。
4. 生成尺寸建议 **3:4 竖版（1024×1365 左右）**，多格横向图用 **4:3**；App 内展示区按 3:4 预留。
5. 需要中文标注的图，提示词里已写明具体文字；若模型中文渲染失败，可改为「无文字，留白待后期加字」，由我在 App 内用文字层叠加（更可靠，推荐）。
6. 风格锚点：**《Bits & Bops》式黑白简笔画**——粗圆线条、无渐变、无阴影渐变、少量网点或斜线表示明暗、可爱但不幼稚、信息优先。

### 统一风格前缀（已内嵌到下面每条提示词，单独使用时可直接复制）

```
黑白简笔画（line art）风格，粗圆头深色线条，纯白背景，无彩色、无渐变、无写实阴影，少量斜线排线表示明暗。类似独立游戏《Bits & Bops》的可爱简约插画风格。构图干净、留白充足、信息优先，适合作为吉他教学 App 的插图。画面中每只手必须恰好 5 根手指，手指弯曲自然、数量正确、不粘连、不畸形。
```

### 通用负面提示词（追加在每条末尾）

```
写实照片, 彩色, 渐变, 复杂背景, 多余手指, 畸形的手, 六指, 手臂断裂, 文字乱码, 水印, 签名, 杂乱线条, 恐怖, 血腥
```

**出图后的检查清单**（每张必过）：

1. 手指数量是否为 5？有无畸形/粘连？
2. 按弦位置是否在品格之间靠近品丝？
3. 视角是否与描述一致（俯视/侧视/正视）？
4. 是否纯黑白、无线条渐变、无彩色渗入？
5. 关键帧之间的手指变化是否真的体现了「保留/移动」？
6. 留白是否足够放文字？

不通过就带着具体问题重生成一次；两次仍不行则降级方案：改画「无手、只有指板 + 圆点标记」的抽象示意图（这类图模型最不容易出错，且教学信息依然完整）。

> 本轮代码线稿的 A/B 组手型图按此降级方案执行：手指数量与按弦位置可控，但形态偏示意。若后续要更写实，优先用上方提示词重出 A1/A2/A5/B1/B2，并保持文件名不变。
