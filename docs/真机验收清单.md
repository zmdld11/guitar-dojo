# 真机验收清单（v0.3.0）

> 现阶段有三件事模拟器做不了：**节拍器漂移**（#8）、**调音器抗泛音**（#12）、
> **乐句播放的听感**（#18/#19：爆音、循环缝隙、变速音高）。前两项在手机 + 吉他上做，
> 第三项只需要耳机或手机外放。做完把数据贴回 issue。

## 一、装包

### 方式 A：自己构建（推荐，能拿到 debug 日志钩子）

```bash
./gradlew installDebug
```

手机需开启开发者选项与 USB 调试。小米/红米如果 `adb install` 报 `INSTALL_FAILED_USER_RESTRICTED`，
先在开发者选项打开「USB 安装」，或把 APK 推到 `/data/local/tmp/` 后执行
`adb shell pm install -r /data/local/tmp/app-debug.apk`。

### 方式 B：从 CI 下载

打开 https://github.com/zmdld11/guitar-dojo/actions ，进最近一次成功的 CI，下载 `app-debug` 产物解压安装。
注意：CI 产物同样是 debug 构建，日志钩子是开的。

## 二、节拍器漂移（issue #8）

目的：证明连续播放时节奏不会越走越偏。

1. 手机连电脑，清空日志：
   ```bash
   adb logcat -c
   ```
2. 开始采集（保持这个终端不要关）：
   ```bash
   adb logcat -s MetronomeDrift > drift.txt
   ```
3. 手机打开 App → 工具 → 节拍器 → 设为 80 BPM、4/4、四分音符 → 开始。
4. **让它跑 30 分钟**。建议：中间锁屏 10 分钟、切到别的 App 几分钟，模拟真实练习场景。
5. 停止播放，终端 `Ctrl+C`。
6. 分析：
   ```bash
   python tools/analyze_drift.py drift.txt --sample-rate 48000
   ```

### 合格线

| 指标 | 合格线 |
| --- | --- |
| 间隔标准差 | < 2 ms |
| 累计漂移峰值 | < 20 ms |
| 漂移斜率 | 绝对值 < 100 ppm |
| AudioTrack 欠载 | 0 |

把分析输出 + 手机型号 + 系统版本贴到 #8。若不达标，按 `docs/节拍器漂移测量.md` 的排查顺序处理。

> 模拟器参考数据：音频时钟比墙钟快 1.8 倍，斜率 -83%，这是模拟器假时钟，不作为结论。

## 三、调音器抗泛音（issue #12）

目的：确认在电吉他真实信号下，判音比现用的 Play 调音器更稳。

### 测试矩阵

每项弹 3 秒长音，观察 App 显示的音名是否稳定、偏差方向是否正确。

| # | 项目 | 设置 |
| --- | --- | --- |
| 1 | 六根空弦 | 琴颈拾音器（拨杆朝上），音箱 CLEAN，音量正常 |
| 2 | 六根空弦 | 琴桥拾音器（拨杆朝下）——泛音更强，最容易误判 |
| 3 | 六根空弦 | 琴桥 + 音箱失真通道 |
| 4 | 12 品泛音 | 任意拾音器，检查会不会被误判成别的音 |
| 5 | 轻拨 vs 重拨 | 同一根弦，看轻拨时会不会掉读数 |

### 记录表（复制到 issue 里填）

| 项目 | 弦 | 期望 | App 显示 | 稳定吗 | Play 调音器显示 |
| --- | --- | --- | --- | --- | --- |
| 1 | 6 | E2 | | | |
| 1 | 5 | A2 | | | |
| 1 | 4 | D3 | | | |
| 1 | 3 | G3 | | | |
| 1 | 2 | B3 | | | |
| 1 | 1 | E4 | | | |

「稳定吗」填：稳 / 偶尔跳 / 一直跳。

### 判定

- **通过**：六根弦在三个拾音器/音色组合下都能稳定出正确音名，且 App 明显比 Play 调音器少误判
- **需要调参**：给出具体是「哪根弦、哪个拾音器、显示成了什么」，我按现象调 `peakRatio` / `minClarity` / 平滑窗口

## 四、乐句播放（#18 / #19）

### 听感检查

1. 乐句库 → 打开「爬格子 · 基础四连音」→ 点一个小节设循环 A，再点另一个设 B。
2. 依次试 0.25x / 0.5x / 0.75x / 1.0x / 1.25x / 1.5x，每个速度听 15 秒。
3. 关闭/打开「节拍」开关，确认拍点与音符仍然对齐。

| 项目 | 合格线 |
| --- | --- |
| 变速 | 音高不变，不出现「慢放变调」 |
| 循环 | A/B 边界无爆音、无明显空隙；尾音自然延续 |
| 节拍 | 打开节拍时，咔哒声与音符起音对齐，不越来越偏 |
| 音色 | 无明显削波破音；低音 E 与高音 E 都能听清音高 |

### 本地谱加载

```bash
adb push local_phrases/红莲华.json \
  /sdcard/Android/data/dev.zmdld11.guitardojo/files/phrases/honglianhua.json
```

重启 App → 乐句库 → 筛选「本地」→ 应看到 135 小节的长谱，TAB 横向滚动流畅；
点播放，自动滚动到当前小节。同样的文件也可用乐句库右上角「导入」走系统文件选择器。

> 长谱只用于验证渲染与滚动；版权内容不要提交到仓库。
