# M5 跟弹考核设计（v0.5.0）

> 状态：已实现（2026-11-21）。对应 issue #26–#29。
> 目标：用麦克风判断「音对不对、拍子稳不稳」，给出可解释的音准/节奏双维评分与逐音错误定位，并把评分写进 attempt 驱动次日计划。
> 原设计稿（2026-10-24 版）与实现的差异见文末 §9 实现偏差表。

## 1. 范围

**做**

- 单音乐句的跟弹判定（8 条内置乐句中 7 条自动判定，E5 强力和弦 Riff 回退自评）。
- 音准分：每个期望音与检测频率的音分偏差，±0.7 半音内算命中。
- 节奏分：起音相对期望位置的偏差，±150 ms 内算准时。
- 结果页：总分/音准/节奏、错音定位到小节、重考一次、我的录音与示范 A/B 回放。
- 评分写入 `attempt.score_accuracy / score_rhythm`，经 AssessPolicy 驱动 M4 计划引擎。

**不做（1.0 前）**

- 和弦/扫弦/闷音的自动评分（回退自评）。
- 推弦、滑音、泛音的精确判定（检测器会跟住音高变化，v1 不专门处理）。
- 实时逐音反馈（先录完整段再评分，避免 UI 与音频线程耦合）。
- 录音落盘（内存缓冲，退出即弃）。

## 2. 判定管线

```
PracticeEngine(只放拍点)     MicrophoneCapture
        │ 拍点流                    │ 48kHz 单声道 PCM
        │                          ▼
        │                     TakeBuffer（录音缓冲）
        │                          ▼
        └── 期望拍点 ──▶ ClickAnchor ──▶ 全局样本偏移（锚）
                                   ▼
                      NoteEventExtractor（音高序列 → 音符事件）
                                   ▼
             assessmentTargets（期望音 + 期望拍点，来自 PracticePlan）
                                   ▼
             PerformanceAligner（贪心顺序匹配 + 逐音判定）
                                   ▼
             PerformanceScores（音准 / 节奏 / 总分 + NoteVerdict）
```

- **考核时只放拍点**（`PracticeMixer.phraseMuted`）：麦克风只听到用户的琴。原设计稿「先播示范再静音采集」的串音问题从根上消除；代价是考核考的是凭记忆弹——它本来就是练了 15 分钟之后的考核。
- **拍点锚定**：录音先过 700 Hz 一阶高通（拍点 1.2/1.8 kHz，吉他基频 82–330 Hz，高通把两者分开），块 RMS 包络找瞬态起音；对每个候选起音假设一个偏移并数期望拍点命中数，取命中最多者。一次解出「引擎起点 + 扬声器延迟 + 麦克风延迟」，等价于原设计稿的「中位偏移补偿」——整体晚一点不毁节奏分。
- **录音 → 离线分析**：最后拍点 + 1.5 s 尾音自动停，Dispatchers.Default 分析；分析期 UI 显示「分析中」。

## 3. 事件提取与对齐

**NoteEventExtractor**：滑窗 MPM（窗 2048、跳 1024，与调音器同一检测器）→ 频率转 midi 取整 → 三点中值平滑压单窗误检 → 相邻同音高窗口聚合成事件（最短 80 ms）→ RMS < 0.01 切静音。

**PerformanceAligner**：期望音按时间排序，逐个在「起音 ± 节奏容差」窗口里找第一个未占用的事件。

| 判定 | 条件 |
|---|---|
| CORRECT | 音高命中且起音在容差内（延音覆盖也计入） |
| WRONG_PITCH | 找到事件但音高差 > 0.7 半音 |
| WRONG_TIMING | 音高命中但起音偏差 > ±150 ms |
| MISSING | 窗口内没有可用事件 |
| EXTRA | 没被任何期望音认领的事件 |

**评分**：accuracy = 音高命中数 / 期望音数；rhythm = 命中音里起音在容差内的占比；total = 均权。

**延音覆盖**：同音高的连续期望音可共用一个尚未结束的事件（重复音、拖拍延音）；前一音音高不对时延音不作数。重新触发的同音重复与延音在 v1 不可区分，统一按覆盖处理（宽松方向）。

## 4. 参数（可调处）

| 参数 | 默认 | 位置 |
|---|---|---|
| 音准判错容差 | ±0.7 半音 | `PerformanceAligner` 构造参数 |
| 起音判错容差 | ±150 ms | `PerformanceAligner` 构造参数 |
| 干净 = 音准 ≥ 90% 且节奏 ≥ 85% | — | `PlanRules.assessClean*` |
| 轻松 = 音准 ≥ 95% 且节奏 ≥ 90% | — | `PlanRules.assessEasy*` |
| 拍点锚命中数下限 | max(3, 期望拍点/3) | `ClickAnchor` |
| 事件最短时长 | 80 ms | `NoteEventExtractor` |
| 事件提取 RMS 门限 | 0.01 | `NoteEventExtractor` |

## 5. 回退矩阵

| 场景 | 行为 |
|---|---|
| 乐句含和弦（同 tick 多音） | 自评三档 +「中途停过」（M4 路径）；考核页有「不弹，改自评」入口 |
| 乐句加载失败 | 自评路径 |
| 麦克风不可用/权限拒绝 | 回到就绪态给错误文案；可重试或改自评 |
| 拍点锚定失败 | 偏移取 0，判定照常（起音偏差可能整体偏移一个固定延迟） |

## 6. 数据与计划联动

- 评分写入 `attempt.score_accuracy / score_rhythm`（M4 预留列），JSON 导出同步带出，日历单日明细显示两维分数。
- `AssessPolicy`（`:core:plan`）：(accuracy, rhythm, stopped, bpm, targetBpm) → `AttemptRecord.clean / reachedTargetSpeed / selfRating`。引擎输入结构不变，只换来源（M4 §1.4 的预留路径）。`stopped` 一票否决。
- 考核差 → 引擎次日生成降速重练项（失败分支在 M4 引擎单测覆盖）。

## 7. 结果页

- 总分/音准/节奏百分比一行；「中途停过」红字提示。
- 错误逐行列出：小节号 + 音高不对（偏高/偏低 N 音分）/ 起音晚了 N 毫秒 / 漏弹 / 多弹的音；末行汇总「其余 N 个音正确」。
- 回放：「听我的录音 / 听示范」，再点停止；示范走引擎原速一遍。
- 底部：「重考一次」「确认成绩」。确认后写 attempt 并推进步骤。

## 8. 测试

**`:core:audio`（assess 包 + mixer）**

- TakeBuffer：累积/复制/密封/清空。
- NoteEventExtractor：两段音切分与音高、纯静音、短脉冲过滤、半音、泛音乐句。
- ClickAnchor：含琴声底噪恢复偏移（±1 块）、无拍点返回 null、空期望返回 null。
- PerformanceAligner：完美演奏、WRONG_PITCH、WRONG_TIMING、MISSING、EXTRA、评分单调性、延音覆盖、空期望。
- PracticeMixer：phraseMuted 不渲染音符与音符脉冲。

**`:core:plan`**

- AssessPolicy 8 例：满分/达标区间/低于阈值/单维不足/停过/未达速/边界/规则可调。

**`:core:phrase`**

- isMonophonic：单音、同 tick 双音、空音符。

**真机**：管线与 UI 走查（权限、只放拍点、录音→分析→结果页渲染、录音回放）；判定主观可用性需要拿真琴验收——正常弹、故意按错、漏弹各几次，对照分数（待用户验收）。

## 9. 实现偏差（相对 2026-10-24 设计稿）

| 项 | 设计稿 | 实现 | 原因 |
|---|---|---|---|
| 模块 | 独立 `:core:assessment` | `core:audio/assess` 包 | 判定与音频引擎同源（复用 MPM、PracticePlan 时间轴），单独建模块只增加接口拷贝 |
| 对齐 | DTW（删除/插入惩罚） | 贪心顺序匹配 + 拍点锚全局偏移 | 考核有拍点锚，速度被锚死，DTW 处理的「忽快忽慢」不存在；贪心实现与行为都更可解释 |
| 窗口跳跃 | hop 512（10.7 ms） | hop 1024（21.3 ms） | 30 s 录音约 1400 窗，hop 512 在设备上分析偏慢；onset 精度 150 ms 容差下 21 ms 足够 |
| 录音存储 | 落盘 WAV，保留最近 10 次 | 内存缓冲，退出即弃 | 隐私优先；#28 的 A/B 对比在结果页即时完成，无回看历史需求 |
| 音准容差 | ±50 音分 | ±0.7 半音（70 音分） | midi 取整误差 ±50 音分，留 20 音分余量；±50 会把取整误差判错 |
| 节奏容差 | ±80 ms + 中位偏移补偿 | ±150 ms + 拍点锚全局偏移 | 锚偏移含扬声器/麦克风链路固定延迟；150 ms ≈ 八分音符 @ 40 BPM（最低练习速度） |
| 结果结论 | 四档（优秀/通过/再练/不熟） | 双维百分比 + 逐音错误行 | 干净/达标的阈值语义在 PlanRules（90%/85%），四档结论与引擎输入无对应关系，先不加 |
| 考核音频 | 先播示范再静音采集 | 全程只放拍点 | 示范静音从根上消除扬声器串音，无需自适应噪声底对抗串音 |
| 手动改判 | manualOverride | 未做，用「重考一次」替代 | 个人使用，弹一次不满意直接重弹比改判更真实 |
| onset 检测 | 自适应噪声底 | RMS 固定门限 + 拍点锚 | 安静环境下固定门限够用；真琴验收若发现误检再引入 |
